# apps/mobile — Инспекция (без изменения кода)

> Цель: определить состояние `apps/mobile` для закрытия Phase 2. Никакой код не изменялся. Проведена
> статическая инспекция файлов и реальная сборка `expo export --platform web` (только web-платформа,
> не требует нативного SDK).

## 1. Является ли apps/mobile действительно stub

**Нет, это не чистый stub.** Приложение содержит рабочую конфигурацию Expo Router, корневой layout,
подключающий все общие пакеты (`@atlas/ui`, `@atlas/hooks`, `@atlas/observability`, `@atlas/api`,
`@atlas/auth`, `@atlas/i18n`), и точку входа `index.tsx`. Однако оно находится в состоянии
**скелета/каркаса (scaffold)**: структура маршрутизации и провайдеры готовы, но реальных экранов
нет.

## 2. Есть ли app.json или app.config.ts/js

**Нет.** В репозитории (корень, `apps/*`, `packages/*`, вне `node_modules`) отсутствуют `app.json`,
`app.config.ts`, `app.config.js`. У Expo-приложения нет ни нативного конфига, ни плагинов
(`expo-router`, `expo-splash-screen` и прочие требуют объявления в `app.json`/`app.config.js`). Без
него `expo prebuild`/`expo run:ios`/`expo run:android` не сгенерируют нативные проекты Xcode/Gradle.

## 3. Есть ли Expo Router

**Да.** `expo-router@~4.0.0` указан в `dependencies`, `main` = `expo-router/entry`, присутствуют
`app/_layout.tsx` (корневой `Stack`) и `app/index.tsx`. Сборка `expo export --platform web` успешно
разрешает `expo-router/entry` и компилирует 1397 модулей — маршрутизатор работает.

## 4. Есть ли реальные экраны

**Нет.** Группы маршрутов пусты:

- `app/(auth)/` — **пусто** (нет `login.tsx`);
- `app/(tabs)/` — **пусто**;
- `components/`, `assets/`, `e2e/` — **пусты**.

`app/index.tsx` делает `<Redirect href="/(auth)/login" />`, но целевой файл `app/(auth)/login.tsx`
отсутствует → в рантайме это привело бы к «Unmatched route» / 404. Реальные UI-экраны не
реализованы.

## 5. Можно ли запустить Expo после установки SDK

- **Web (без нативного SDK):** уже работает — `expo export --platform web` завершается успешно
  (`EXIT=0`), бандл собирается. `expo start` (web) тоже поднимется без Xcode/Android.
- **iOS:** требует Xcode + iOS Simulator. `xcrun` присутствует, но полноценный нативный рантайм в
  этом окружении не запускался и не проверялся. Для работы нужен `app.json`/`app.config.js` +
  `expo prebuild` + симулятор.
- **Android:** требует Android SDK/эмулятор (`ANDROID_HOME` не задан) — недоступно.

## 6. Что именно отсутствует для полного закрытия Phase 2

| Что нужно                                                | Статус                     |
| -------------------------------------------------------- | -------------------------- |
| `app.json` / `app.config.js` (нативный конфиг Expo)      | ❌ отсутствует             |
| Реальные экраны: `app/(auth)/login.tsx`                  | ❌ отсутствует             |
| Реальные экраны: хотя бы один таб `app/(tabs)/index.tsx` | ❌ отсутствует             |
| `components/` с переиспользуемыми UI-компонентами        | ❌ пусто                   |

## Вердикт

`apps/mobile` — **функциональный каркас, а не готовое приложение**. Он типчектится, бандлится (web)
и корректно подключает все общие пакеты, но не имеет нативного конфига и реальных экранов, поэтому
«живой» нативный рантайм не подтверждён. Phase 2 по mobile закрывается на ~80%: сборка/типы/
web-рантайм — да; нативный рантайм и реальные экраны — нет.
