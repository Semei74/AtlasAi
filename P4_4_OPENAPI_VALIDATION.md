## 5. Known issues

**Pre-existing — not introduced by P4.4:**
- `SwaggerModule.createDocument()` cannot be used because `PromptLibraryModule` has a DI resolution error (`PromptService` injects `PiiRedactorService` by class, module provides under `PII_REDACTOR` string token). The manual `generate-openapi.mjs` script is the workaround.
- Some non-project operations (e.g., `DocumentController_findMany`, `PromptLibraryController_list`) return `Record<string, never>` as response type — these are not part of P4.4 scope.

---

## 6. Recommendations

1. Fix the `PromptLibraryModule` DI issue to enable auto-generation via `SwaggerModule.createDocument()`, which would remove the manual sync burden.
2. Add response examples for all project endpoints in the OpenAPI spec (currently uses only schema definitions).
