# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

**Do not** open a public issue. Email the project maintainers directly.

## Process

1. Report received — acknowledged within 48 hours
2. Investigation — determine impact and severity
3. Patch development — fix prepared
4. Release — patch deployed, disclosure coordinated

## Supported Versions

Only the latest major release receives security patches.
